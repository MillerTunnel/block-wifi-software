## 🔧 Troubleshooting

| **Problem** | **Fix** |
|--------------|-----------|
| **Can't access router** | Reset and re-apply whitelist |
| **Device keeps reconnecting** | Block at router, not just OS |
| **MAC randomization** | Disable randomized MAC on device |
| **Rogue AP not found** | Use a Wi-Fi scanner with signal map |
| **Script fails** | Run as administrator / root |
| **Whitelist locks you out** | Add your device first |
